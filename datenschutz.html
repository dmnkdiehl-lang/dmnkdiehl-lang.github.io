Datenschutzerklärung – Kanal-Zahlen

Stand: 8. Oktober 2026

Wer ist verantwortlich?

Dominik Diehl, E-Mail: dmnkdiehl@gmail.com

Wer nutzt das Werkzeug?

Nur der Betreiber selbst, für seine eigenen YouTube-Kanäle. Das Werkzeug wird nicht angeboten und hat keine anderen Nutzer.

Welche Google-Daten werden genutzt?

  • Statistiken der eigenen YouTube-Kanäle (z. B. Aufrufe, Wiedergabezeit, Impressionen, Klickrate) über die YouTube Analytics API und die YouTube Reporting API.
  • Kanal- und Videoinformationen der eigenen Kanäle (z. B. Titel, Liste der hochgeladenen Videos) über die YouTube Data API.
  • Hochladen eigener Videos, Thumbnails, Playlist-Einträge und eines Kommentars auf die eigenen Kanäle über die YouTube Data API.

Wie werden die Daten verwendet und gespeichert?

Die Daten werden nur für die Auswertung und Veröffentlichung der eigenen Videos verwendet. Sie werden ausschließlich auf dem Computer des Betreibers gespeichert. Die Zugangsschlüssel (OAuth-Tokens) liegen dort in Dateien, die nur der Betreiber lesen kann.

Werden Daten weitergegeben?

Nein. Es werden keine Daten verkauft, weitergegeben, für Werbung genutzt oder an Dritte übertragen.

Widerruf und Löschung

Der Zugriff kann jederzeit in den Google-Kontoeinstellungen widerrufen werden: https://security.google.com/settings/security/permissions. Gespeicherte Daten werden auf Anfrage an die oben genannte E-Mail-Adresse gelöscht.

YouTube und Google

Das Werkzeug nutzt die YouTube API Services. Es gelten die Nutzungsbedingungen von YouTube und die Datenschutzerklärung von Google.
