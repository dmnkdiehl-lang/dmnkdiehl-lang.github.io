Five Star Uploader

Five Star Uploader is a personal desktop & local creator workflow tool used to organize, review, and publish vertical 9:16 gaming highlight clips to the creator's own TikTok account (@fivestarclipsgaming).

How it works

  • TikTok Login Kit: Authenticates the creator's TikTok account via official OAuth 2.0.
  • Content Posting API (Direct Post): Uploads manually reviewed and approved highlight clips with creator-defined titles, captions, hashtags, and privacy settings directly to TikTok.
